# Project memory

This folder contains durable context for AI coding sessions.

- [PROJECT.md](PROJECT.md) describes the repository as it exists today.
- [DECISIONS.md](DECISIONS.md) records decisions future contributors should preserve.

The root [AGENTS.md](../AGENTS.md) instructs compatible AI coding agents to read
and maintain these files. Keep this folder free of secrets, personal information,
temporary plans, and generated logs.
