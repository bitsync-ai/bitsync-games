# Pixel Slugger

A one-button pixel-art baseball batting game built with Phaser.

## Play

- Press <kbd>Space</kbd>, <kbd>Enter</kbd>, or tap to start.
- Swing when the timing marker reaches the gold zone.
- Build a streak and chase the high score before making three outs.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Production build

```bash
npm run build
```

The static site is written to `out/`. The repository-level workflow builds
and publishes it as part of the complete BitSync Games site.

High scores are stored locally in the browser.
